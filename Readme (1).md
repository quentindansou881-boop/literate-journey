## 1. Цель бизнес-кейса
Оценить, как покупатели маркетплейса Olist используют рассрочку при оплате банковской картой: какова доля платежей в рассрочку, каков типичный срок, как срок связан с суммой платежа и чем различаются месяцы и штаты.

## 2. Источник данных
Brazilian E-Commerce Public Dataset by Olist (Kaggle, CC BY-NC-SA 4.0), 9 таблиц за 2016–2018 гг. Используются order_payments и orders (через слой CORE).

## 3. Архитектура
Kaggle Olist → Python → RAW → STAGING → CORE → SQL VIEW `dm_v11_card_installments` → CSV → Yandex DataLens. Хранилище — SQLite (`olist_dwh.sqlite`), среда — Google Colab.

## 4. SQL-витрина
Файл `sql/dm_v11_card_installments.sql`. Гранулярность: 1 строка = 1 платёж картой (`order_id` + `payment_sequential`). Витрина объединяет платежи с `core_order` по `order_id` (связь «один к одному» со стороны заказа), поэтому строки не размножаются и выручка не завышается. Исключены платежи с `payment_installments = 0` (аномалия данных). Описание полей — `data/dm_v11_card_installments_dictionary.csv`.

## 5. Метрики (DataLens)
| Метрика | Формула |
|---|---|
| Платежей | `COUNTD([payment_key])` |
| Выручка по картам | `SUM([payment_value])` |
| Доля платежей в рассрочку | `SUM([is_installment]) / COUNTD([payment_key])` |
| Среднее число платежей | `SUM([payment_installments]) / COUNTD([payment_key])` |
| Средний платёж | `SUM([payment_value]) / COUNTD([payment_key])` |

Средние от средних не используются: все показатели считаются как отношение сумм.

## 6. Дашборд
Индикатор KPI, линейная, столбчатая, кольцевая и комбинированная диаграммы; селекторы по месяцу покупки и штату клиента. Скриншоты — в папке `img/`.

## 7. Результаты

### Контрольные расчёты
1. Число платежей картой: витрина = 76 793, источник (STAGING, `credit_card`, рассрочек ≥ 1) = 76 793 — совпадает.
2. Сумма `payment_value`: витрина = 12 541 895,56 BRL, источник = 12 541 895,56 BRL — совпадает. Дублей `payment_key` нет, платежей без заказа нет.

### Выводы
1. 66,9 % платежей картой оформлены в рассрочку (51 338 из 76 793); на них приходится 80,5 % суммы платежей по картам (12,54 млн BRL).
2. Средний платёж в рассрочке — 196,76 BRL против 95,87 BRL без рассрочки; чем длиннее рассрочка, тем выше платёж: 134,23 BRL при 2–3 платежах, 181,32 при 4–6, 333,83 при 7–10 и 358,34 BRL при 11 и более. Среднее число платежей по всем платежам картой — 3,51.
3. Среди штатов с не менее чем 100 платежами самый большой средний срок в Параибе (PB): 4,68 платежа (428 платежей); далее SE — 4,58, RO и AL — по 4,41. Крупнейший штат SP даёт наибольшую сумму платежей по картам (4,68 млн BRL).

### Рекомендация
Рассрочка — основной инструмент оплаты дорогих покупок: платежи от 7 платежей в среднем более чем втрое дороже платежей без рассрочки. Имеет смысл продвигать рассрочку для дорогих корзин и в штатах с высоким средним сроком (PB, SE, RO, AL), где покупатели чаще растягивают оплату, и отдельно отслеживать риск неплатежей в группе 11+ платежей.

## 8. Ограничения данных
- Один заказ может содержать несколько платежей, поэтому считаются платежи, а не заказы.
- Исключены 2 платежа картой с нулём рассрочек (аномалия данных); способы оплаты `not_defined` (3 платежа) в витрину не входят.
- Данные охватывают только 2016–2018 гг. и один маркетплейс; в малых штатах мало наблюдений.
